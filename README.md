# Sistema de Control de Rescate y Adopción Animal

## Descripción
Sistema de software para registrar animales rescatados, gestionar su atención y facilitar los procesos de adopción.

## Objetivo
Organizar la información de los animales, los rescatistas y los adoptantes para mejorar el seguimiento de los rescates y las adopciones.

## Funcionalidades principales
- Registrar animales rescatados.
- Consultar información y estado de cada animal.
- Registrar adoptantes.
- Gestionar solicitudes de adopción.
- Notificar cambios en el estado de una adopción.

## Patrones de diseño
- **Factory Method:** creación de objetos relacionados con los registros del sistema.
- **Repository:** organización del acceso a los datos.
- **Observer:** notificación de cambios importantes.

## Estructura
- `docs/`: documentación del proyecto.
- `src/`: código fuente.
- `diagrams/`: diagramas UML.

## Tecnologías y herramientas
- Git y GitHub para el control de versiones.
- UML para representar el diseño del sistema.
